# Brandon Fitness

Upload every file from this folder to the root of your GitHub repository.

Required files:

- index.html
- styles.css
- app.js
- manifest.json
- service-worker.js
- icon.svg
- README.md

## Publish through GitHub Pages

1. Open repository Settings.
2. Open Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select the main branch and / (root).
5. Save.
6. Wait a few minutes for the site link.
7. Open the link in Safari.
8. Tap Share, then Add to Home Screen.

Workout data is stored locally on your device. Export backups regularly.
